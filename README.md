# أكاديمية القدرات | GAT Academy على Railway

الموقع ولوحة المشرف وقاعدة البيانات في مشروع واحد على Railway، دون الحاجة إلى Firebase أو أي خدمة أخرى.

- **الموقع:** الحقيبة كاملة، والنماذج الثلاثون، ولوحة التقدم.
- **الحسابات:** تسجيل الطلاب بالبريد وكلمة المرور. كلمات المرور مشفّرة بـ bcrypt، والجلسات آمنة بملفات تعريف `HttpOnly`.
- **التسجيل قبل أول اختبار:** يُطلب من الطالب إنشاء حساب (أو الدخول) عند بدء أي اختبار أو تدريب لأول مرة، ثم يبدأ الاختبار مباشرة بعد التسجيل.
- **الحفظ:** يُحفظ تقدم كل طالب في قاعدة بيانات Postgres، ويتبعه إلى أي جهاز يدخل منه.
- **لوحة المشرف** على `/admin.html`، وفيها:
  - إحصاءات الطلاب وتوزيع درجاتهم.
  - جدول الطلاب مع البحث والترتيب.
  - تصدير الجدول بصيغة CSV.
  - إنشاء كلمة مرور مؤقتة لطالب نسي كلمته.
  - حذف حساب.

## النشر (نحو ١٠ دقائق)

### ١. ارفع المشروع

اختر إحدى طريقتين:

**أ) عن طريق GitHub (الأسهل):**

١. ارفع محتويات هذا المجلد إلى مستودع جديد في GitHub، دون مجلد `node_modules`.
٢. في Railway اختر **New Project ← Deploy from GitHub repo** ثم اختر المستودع.

**ب) عن طريق سطر الأوامر:**

١. ثبّت Node.js من <https://nodejs.org>.
٢. افتح الطرفية داخل هذا المجلد ونفّذ:

```bash
npm install -g @railway/cli
railway login
railway init
railway up
```

### ٢. أضف قاعدة البيانات

١. في لوحة المشروع اختر **+ Create ← Database ← PostgreSQL**.
٢. ستُنشأ قاعدة البيانات خلال ثوانٍ.

### ٣. اضبط المتغيرات

افتح خدمة الموقع (وليس قاعدة البيانات) ثم تبويب **Variables**، وأضف متغيرين:

| المتغير | القيمة |
|---|---|
| `DATABASE_URL` | `${{Postgres.DATABASE_URL}}`، وهو متغير مرجعي يربط الموقع بقاعدة البيانات |
| `ADMIN_EMAILS` | بريدك. لأكثر من مشرف افصل بينها بفاصلة: `a@x.com,b@y.com` |

تُعاد تهيئة الخدمة تلقائيًا بعد الحفظ. ويُنشئ الخادم جداول قاعدة البيانات بنفسه عند أول تشغيل.

> **عن SSL:** الرابط الداخلي `${{Postgres.DATABASE_URL}}` لا يحتاج SSL ويعمل كما هو. إن استخدمت الرابط العام (`DATABASE_PUBLIC_URL`) وفيه `?sslmode=require` فالخادم يتعامل معه تلقائيًا. ولفرض SSL أو تعطيله يدويًا أضف المتغير `PGSSL` بقيمة `1` أو `0`.

### ٤. أنشئ الرابط العام

١. من خدمة الموقع افتح **Settings ← Networking ← Generate Domain**.
٢. يظهر لك رابط مثل `https://masar100-production.up.railway.app`، وهو الرابط الذي ترسله للطلاب.
٣. إن أردت نطاقك الخاص، أضفه من **Custom Domain** في الصفحة نفسها.

### ٥. ادخل مشرفًا

١. افتح الموقع، ثم سجّل حسابًا من زر الحساب (أيقونة الشخص) بالبريد نفسه الذي وضعته في `ADMIN_EMAILS`.
٢. افتح `/admin.html` فتظهر لك لوحة التحكم.

## البيانات المحفوظة (أقل قدر ممكن)

| الجدول | الحقول |
|---|---|
| `users` | اسم الطالب أو الطالبة، البريد، كلمة المرور مشفّرة (لا يمكن قراءتها)، تاريخ التسجيل |
| `progress` | المسار، الهدف، لغة الواجهة، موعد الاختبار إن أُدخل، ملف التقدم، ملخص للوحة المشرف، تاريخ آخر تحديث |
| `sessions` | رمز الجلسة مشفّرًا وتاريخ انتهائه (٦٠ يومًا) |

- الاسم فقط لعرضه في أعلى الصفحة ولوحة المشرف. لا رقم جوال ولا هوية.
- يوافق الطالب صراحةً على حفظ البيانات عند التسجيل.
- يستطيع الطالب حذف حسابه وكل بياناته بنفسه من نافذة الحساب.
- حذف الحساب، سواء من الطالب أو من المشرف، يحذف معه تقدمه وجلساته.

## الأمان

- **الاتصال:** مشفّر عبر HTTPS تلقائيًا على Railway.
- **حماية من الهجمات:** سياسة أمان محتوى (CSP) صارمة، وحماية من طلبات المواقع الأخرى (CSRF).
- **محاولات الدخول:** ١٠ محاولات فاشلة للبريد نفسه من الجهاز أو الشبكة نفسها خلال ١٥ دقيقة، فلا يستطيع أحد إقفال حساب طالب بمحاولات خاطئة من جهازه. ومع ذلك يوجد حد أعلى لكل بريد (١٠٠ محاولة فاشلة من كل الشبكات) يوقف التخمين الموزّع، وحد واسع لكل عنوان IP يكفي فصلًا كاملًا يدخل من شبكة المدرسة نفسها.
- **الأجهزة المشتركة:** إذا دخل طالب آخر من المتصفح نفسه لا يُدمج تقدم الطالب السابق في حسابه.
- **تصدير CSV:** بترميز UTF-8 مع BOM ليظهر النص العربي صحيحًا في Excel، مع حماية من خلايا الصيغ.
- **فصل البيانات:** كل طالب يصل إلى بياناته فقط. واجهات المشرف مقصورة على البُرُد المذكورة في `ADMIN_EMAILS`.
- **تغيير كلمة المرور:** عند تغييرها تُلغى جلسات الطالب على الأجهزة الأخرى.

## نسيان كلمة المرور

لا يرسل الموقع رسائل بريد، حتى لا يحتاج إلى خدمة بريد مدفوعة. إذا نسي طالب كلمة مروره:

١. ينشئ له المشرف كلمة مرور مؤقتة من لوحة التحكم.
٢. يرسلها المشرف إليه.
٣. يدخل الطالب بها، ثم يغيّرها من نافذة الحساب.

يمكن لاحقًا إضافة إرسال رابط الاستعادة بالبريد عبر خدمة بريد (مثل Resend).

## التكلفة

- يعمل المشروع بخادم صغير وقاعدة بيانات واحدة، واستهلاكه منخفض.
- راجع الأسعار الحالية لـ Railway على <https://railway.com/pricing>. خطة Hobby تتضمن رصيد استخدام شهريًا يكفي عادةً مشروعًا بهذا الحجم في بدايته.

## الملفات

```
server.js       الخادم: الحسابات، الحفظ، واجهات المشرف، وتقديم الموقع
public/         الموقع (index.html, app.js, app.css, cloud.js, favicon.svg, 404.html) ولوحة المشرف (admin.html, admin.js)
railway.json    إعدادات التشغيل وفحص الصحة (/healthz)
package.json    المكتبات: express, pg, bcryptjs
```

للتشغيل على جهازك: `npm install`، ثم ضع قيمتي `DATABASE_URL` و`ADMIN_EMAILS`، ثم `npm start`.

## النطاق الخاص (gat.academy)

- النطاقان `gat.academy` و`www.gat.academy` مضافان إلى خدمة الموقع، وسجلاتهما في Namecheap: `ALIAS @ → 51lsmios.up.railway.app` و`CNAME www → igjdm2j1.up.railway.app`.
- `CANONICAL_HOST=gat.academy` مع `REDIRECT_HOSTS=www.gat.academy,masar100-web-production.up.railway.app` يحوّلان أي زيارة لهذين العنوانين إلى `https://gat.academy` تحويلًا دائمًا (301).
- `robots.txt` و`sitemap.xml` يُولَّدان تلقائيًا، ولوحة المشرف وواجهات `/api` مستثناة من الفهرسة.
